# Мой способ установки Arch Linux
Все вы знаете Arch Linux, про его ручную установку. Для меня это легко. А скриптом - быстрее!
Я сделал свой скрипт, который устанавливает дальше Arch в chroot.
Что нужно сделать, чтобы запустить скрипт:
1. Скопировать его через команду:
```bash
curl -fLO https://ayone.is-a.dev/files/archauto.sh
```
2. Изменить скрипт по своему - обязательный этап. Иначе, если вы на Virtual Machine, вы можете нажать Enter.
3. Если вы изменили скрипт - запустить:
```bash
sudo bash archauto.sh
```
**ПРИМЕЧАНИЕ:** Обязательно привяжите разделы /boot/efi и /, иначе grub-install выдаст ошибку несуществующего каталога /boot/efi.

**ЕЩЕ ПРИМЕЧАНИЕ:** Код пока что тестовый, в нем не добавлена настройка sudo.
