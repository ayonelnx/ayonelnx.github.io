# Archexy v2.0
Я сделал свой установщик Arch GNU/Linux для тех, кому лень устанавливать вручную или для тех, кто ненавидит archinstall. Скрипт теперь называется Archexy.
### Что нового?
1. Добавлена настройка sudo без пароля
2. Реализован выбор оболочек и оконных менеджеров. Основа - Whiptail
3. Реализована автоустановка драйверов под ваше железо. Имеется только NVIDIA, AMD и Intel. Для нераспознанных будет установлен только mesa. Основа - lspci
### Что будет реализовано в ближайшее время?
1. Полностью TUI-установщик (к v2.3 версии приблизительно)
2. Дополнительные программы (к v2.1)
3. Побольше оболочек (к v2.1)

Тестируйте на свой страх и риск.
## Установка
1. Установите Vim, Nano или Micro.
2. Скачайте скрипт одной командой:
```
curl -fLO https://ayone.is-a.dev/files/archexy.sh
```
3. Подправьте скрипт под себя: vim archexy.sh | nano archexy.sh | micro archexy.sh
4. Запуск: sudo bash archexy.sh
